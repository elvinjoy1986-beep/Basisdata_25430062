1. Mampu menjalankan dan menghentikan layanan MariaDB melalui XAMPP Control Panel serta memeriksa status port 3306.
2. Terhubung ke server MariaDB via CLI dan phpMyAdmin serta memahami perbedaan arsitekturnya.

4. Membangun basis data pertama dan mengelola riwayat pengerjaan proyek menggunakan Git & GitHub.

## 2. Ringkasan Dasar Teori
DBMS berfungsi mengelola penyimpanan, keamanan, dan kueri data secara terpusat tanpa memerlukan aplikasi mengurus berkas mentah. MariaDB bekerja dengan arsitektur klien-server pada port TCP 3306. Setiap kredensial akun MariaDB diidentifikasi berdasarkan pasangan `pengguna@host`. Penerapan prinsip *least privilege* dilakukan dengan membatasi akun kerja harian hanya pada basis data spesifik, sementara Git digunakan untuk mencatat jejak pengembangan berkas skrip secara bertahap.

## 3. Hasil Langkah Percobaan
* Membuka XAMPP Control Panel dan mengaktifkan modul MySQL (MariaDB) pada port 3306.
* Mengakses MariaDB CLI menggunakan tombol Shell dan menjalankan kueri verifikasi versi serta SQL mode.
* Menetapkan password akun `root` pada host `localhost`, `127.0.0.1`, dan `::1`.
* Membuat basis data `kopma_062` dan akun kerja `mhs_062` yang diberi akses khusus pada `kopma_062.*`.
* Mengubah konfigurasi `auth_type` phpMyAdmin menjadi `'cookie'` pada `config.inc.php`.

## 4. Jawaban Titik Analisis
1. **Titik Analisis 1:** Dokumentasi MySQL relevan untuk kueri SQL standar, sedangkan dokumentasi MariaDB wajib digunakan untuk konfigurasi *engine*, otentikasi khusus, dan variabel bawaan MariaDB 10.4.
2. **Titik Analisis 2:** Pesan galat `ERROR 1045 (using password: NO)` menunjukkan bahwa klien mengakses server tanpa menyertakan password.
3. **Titik Analisis 3:** `information_schema` berisi metadata yang diizinkan dibaca oleh semua akun, sedangkan basis data `mysql` berisi otentikasi sensitif. Galat 1045 terjadi pada tahap otentikasi login, sedangkan galat 1044 terjadi pada tahap otorisasi hak akses basis data.
4. **Titik Analisis 4:** Mode `cookie` lebih aman karena kredensial tidak disimpan dalam bentuk *plain-text* di berkas server, melainkan meminta masukan login yang terenkripsi per sesi.
