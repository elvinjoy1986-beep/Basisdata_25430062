1. Tujuan Praktikum
Mampu mengimplementasikan rancangan basis data relasional (3NF) ke dalam bentuk fisik menggunakan DBMS MariaDB / MySQL.

Mampu menggunakan perintah Data Definition Language (DDL) seperti CREATE DATABASE, CREATE TABLE, menetapkan PRIMARY KEY, serta mendefinisikan FOREIGN KEY.

2. Langkah-Langkah Pengerjaan & Perintah SQL
Berikut adalah skrip SQL yang dieksekusi di dalam terminal MariaDB:

A. Membuat dan Menggunakan Database
SQL
CREATE DATABASE basisdata_25430062;
USE basisdata_25430062;

B. Membuat Tabel mahasiswa
SQL
CREATE TABLE mahasiswa (
    id_mahasiswa VARCHAR(20) NOT NULL PRIMARY KEY,
    nama_mahasiswa VARCHAR(100) NOT NULL,
    alamat_mahasiswa TEXT
);

C. Membuat Tabel dosen
SQL
CREATE TABLE dosen (
    id_dosen VARCHAR(20) NOT NULL PRIMARY KEY,
    nama_dosen VARCHAR(100) NOT NULL
);

D. Membuat Tabel mata_kuliah
SQL
CREATE TABLE mata_kuliah (
    kode_mk VARCHAR(20) NOT NULL PRIMARY KEY,
    nama_mk VARCHAR(100) NOT NULL,
    sks INT NOT NULL,
    semester INT NOT NULL,
    id_dosen VARCHAR(20),
    FOREIGN KEY (id_dosen) REFERENCES dosen(id_dosen)
);

E. Membuat Tabel krs_nilai (Tabel Transaksi/Relasi)
SQL
CREATE TABLE krs_nilai (
    id_mahasiswa VARCHAR(20) NOT NULL,
    kode_mk VARCHAR(20) NOT NULL,
    nilai VARCHAR(5),
    ruang VARCHAR(50),
    PRIMARY KEY (id_mahasiswa, kode_mk),
    FOREIGN KEY (id_mahasiswa) REFERENCES mahasiswa(id_mahasiswa),
    FOREIGN KEY (kode_mk) REFERENCES mata_kuliah(kode_mk)
);

3. Verifikasi Struktur Tabel
Perintah untuk mengecek daftar tabel yang telah dibuat:

SQL
SHOW TABLES;
