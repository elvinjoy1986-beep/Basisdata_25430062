## 1. Tujuan Praktikum
1. Menambah data menggunakan sintaks `INSERT` satu baris, banyak baris, dan `INSERT ... SELECT`.
2. Mengubah (`UPDATE`) dan menghapus (`DELETE`) data secara aman dengan mengaktifkan mode `sql_safe_updates`.
3. Menyusun skenario uji positif dan negatif serta mendokumentasikan hasilnya.
4. Menyiapkan data sampel proyek berbasis parameter $P$ yang dapat dibangun ulang secara otomatis.

## 2. Ringkasan Dasar Teori
Data Manipulation Language (DML) digunakan untuk mengelola data di dalam tabel. Pengisian data wajib mengikuti hierarki integritas referensial (tabel induk diisi lebih dahulu dari tabel anak). Penggunaan `sql_safe_updates` mencegah bencana kehilangan data akibat perintah `UPDATE` atau `DELETE` tanpa klausul `WHERE`. Pengujian basis data mencakup uji positif (memastikan data sah diterima) dan uji negatif (memastikan constraint server aktif menolak data yang salah).

## 4. Jawaban Titik Analisis
1. **Titik Analisis 1:** `INSERT ... SELECT` lebih aman karena menjamin konsistensi harga dari katalog barang dan menghindari kesalahan ketik manual. Nota `PJ-2609-0142` tidak berubah saat harga katalog naik karena nilai harganya sudah tersimpan permanen per transaksi (AB-04).
2. **Titik Analisis 2:** Menghapus nota menghapus detailnya akibat `ON DELETE CASCADE`. Menghapus petugas ditolak (`RESTRICT`) untuk melindungi riwayat audit transaksi. Kasir berhenti bekerja ditangani dengan menonaktifkan akun/peran, bukan menghapus barisnya.
3. **Titik Analisis 3:** Pengujian transaksi pembelian yang melebihi stok barang berstatus **GAGAL** karena constraint `CHECK` pada tabel barang hanya mengecek baris tabel itu sendiri, tidak dapat melakukan perbandingan lintas-tabel saat `INSERT` nota dilakukan (menjadi utang desain Modul 14).

## 5. Hasil Latihan dan Modifikasi
1. Pengarsipan anggota nonaktif pra-2025 ke tabel `anggota_arsip` menggunakan `CREATE TABLE LIKE`, `INSERT ... SELECT`, dan `DELETE` aman.
2. Penyesuaian harga makanan naik $5\%$ dibulatkan ke ratusan terdekat dengan fungsi `ROUND((harga * 1.05)/100)*100`.
